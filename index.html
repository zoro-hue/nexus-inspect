      Engineering honesty
      
          
      What this does not do
      
        
      
        
        
          
      • 
            NOT
            
        Deterministic rule-based detection
        Rules identify concrete syntactic patterns and known vulnerability shapes. They cannot evaluate runtime business logic or guarantee zero false negatives.
        
          
        • 
          
      • 
            NOT
            
        Calibrated confidence scores
        Scores reflect AST pattern strength and test calibration, not an exploitability guarantee. Findings serve as prioritized investigation evidence.
        
          
        • 
          
      • 
            NOT
            
        No claims of AI authorship
        NEXUS does not claim to detect AI code by style or guess author intent. We report only what the source code visibly contains.
